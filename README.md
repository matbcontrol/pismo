# Письмо каждому

Новогоднее письмо по личной ссылке. Экран телефона обёрнут бумагой, адресат рвёт её пальцем. Под обёрткой кассовый чек с его цифрами за год, печать, слова от руки и подарок с кодом.

Открыть: https://matbcontrol.github.io/pismo/

Компания и люди в примере вымышленные.

Звуки записаны на микрофон и взяты с freesound.org по лицензии CC0. Авторы перечислены в sfx/CREDITS.txt.
